# Dashboard export

`home-main.json` is a copy of the storage mode dashboard `home-main`, kept here
for history and review. Home Assistant does not read this file.

Dashboards are edited through the Home Assistant MCP server. After every edit,
export the full config again and commit it:

1. Read the dashboard with `ha_config_get_dashboard(url_path="home-main")`.
2. Write the `config` object to `tools/dashboard/home-main.json` (2 space indent).

The floor plan view is generated by `tools/floorplan/view.py` and is part of
this export as well.
